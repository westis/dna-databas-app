# DNA-databas

Betaversion. Här ligger bara installationsfilerna till DNA-databas, ett
program för den som forskar med DNA-matchningar och släktträd. Allt du läser
in stannar på din egen dator.

Ladda ner den senaste versionen under
[Releases](https://github.com/westis/dna-databas-app/releases/latest):

- Windows: `DNA-databas-Windows.exe`
- Mac med Apple-chip (M1 och senare): `DNA-databas-Mac-arm64.dmg`
- Mac med Intel-processor: `DNA-databas-Mac-x64.dmg`

Guiden `installera-appen.pdf` ligger bredvid filerna och visar steg för steg
hur du installerar och kommer igång.

Frågor eller fel: använd *Skicka synpunkter* i appen, eller skriv till
westis+dna@gmail.com.
